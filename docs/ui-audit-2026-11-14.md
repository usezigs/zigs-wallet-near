## Implementation integrity verdict

The product has a coherent visual system worth preserving. Existing icons, panel materials and official asset/provider marks are reused. Financial controls retain their existing handlers. The failing simulation cases share one lifecycle defect: overwriting the dialog class removes the theme scope while leaving its material mounted. This is a real implementation issue rather than a reason to redesign the interface.

The entry markup has no striped page scaffold. These material/functional uses are retained within the pinned visual world. These counts are source signals, not 60 verified user-facing bugs.
